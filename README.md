# Flipnzee Conditional Login Menu

**Flipnzee Conditional Login Menu** is a lightweight WordPress plugin that dynamically adjusts the website's primary navigation based on the visitor's authentication status.

Instead of displaying **Login** and **Sign Up** to users who are already logged in, the plugin automatically replaces them with **Logout**.

## Features

- Shows **Login** and **Sign Up** to logged-out visitors.
- Shows **Logout** to logged-in users.
- Automatically hides Login and Sign Up after authentication.
- Automatically adds a Logout link when required.
- Preserves other navigation items.
- Keeps **Join Affiliate Program** and other existing menu items unchanged.
- Uses WordPress's native authentication and logout functionality.
- Works without modifying the theme.
- Lightweight and focused on a single purpose.

## Navigation Behavior

### Logged-out visitor

```text
Home | Live Auction | Website for Sale | Blog | Trending | About |
Terms | Support | Contact | Login | Sign Up | Join Affiliate Program
```

### Logged-in visitor

```text
Home | Live Auction | Website for Sale | Blog | Trending | About |
Terms | Support | Contact | Logout | Join Affiliate Program
```

## Why Use It?

WordPress menus are normally static, which can result in **Login** and **Sign Up** remaining visible even after a user has authenticated.

This plugin provides a simple dynamic solution without requiring theme modifications or a large membership plugin.

It is particularly useful for marketplaces, membership websites, community platforms, and websites where user accounts are important.

## Compatibility

- WordPress
- Standard WordPress authentication
- Custom navigation menus
- Genesis-based themes and other WordPress themes
- PHP 8.x

## Installation

1. Download the plugin ZIP.
2. Go to **WordPress → Plugins → Add New → Upload Plugin**.
3. Upload the ZIP file.
4. Activate the plugin.
5. Clear any caching layer if necessary.

No configuration is required.
